# YouTube Clone

## Goal
Build a production-level Full Stack YouTube Clone while learning React, Node.js, Express.js, MongoDB, and API integration.

## Tech Stack

### Frontend
- React
- React Router
- Tailwind CSS

### Backend
- Node.js
- Express.js
- MongoDB
- JWT
- Cloudinary

## Learning Strategy

Every feature will be built independently:

Requirement
→ Design
→ Backend
→ Testing
→ Frontend
→ Integration
→ Refactor
